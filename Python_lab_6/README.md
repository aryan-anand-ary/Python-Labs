# Python Lab 6: Decorators and Generators

Exercises covering Python decorators and generator functions.

| File | Description |
|---|---|
| `Basic_Decorator.py` | Decorator that prints messages before and after a function runs |
| `double_result.py` | Decorator that doubles a function's return value |
| `countdown_generator.py` | Generator yielding numbers from n down to 1 |
| `even_numbers_generator.py` | Generator yielding even numbers up to a limit |

Output screenshots are the `.png` files in this repo.

## Run
```bash
python3 Basic_Decorator.py
```
